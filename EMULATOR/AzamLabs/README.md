## 💡 Quick Overview

- ⚡ **95% Lighter**: Idles at **~75 MB RAM** (vs 1,650 MB in legacy emulators).
- 🔄 **Universal Compatibility**: Ingests and runs labs from **EVE-NG** (`.unl`), **PNETLab**, **GNS3** (`.gns3`), **Cisco CML** (`.yaml`), and **Containerlab** (`.clab.yml`).
- 💾 **100:1 Density**: Run 100 Cisco routers on the memory and CPU of just 1 router.
- 🎨 **OLED Cyber-Dark UI**: 60 FPS GPU-accelerated canvas with live glowing traffic particles and in-browser Wireshark.
- 🛡️ **Cyber Range & Cloud Transit**: Built-in Kali/Suricata security testing and direct WireGuard peering to AWS, Azure, and GCP.
- 🔒 **100% Clean-Room**: 100% original code, zero legacy branding or baggage, completely Docker-proof.
